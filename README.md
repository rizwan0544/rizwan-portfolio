# Muhammad Rizwan Akram — Portfolio

Personal portfolio website for **Muhammad Rizwan Akram**, a Senior Full Stack Developer (PHP, Laravel, Node.js, React.js, Vue.js) with 7+ years of experience.

Built with [Next.js](https://nextjs.org) (App Router) and [Tailwind CSS](https://tailwindcss.com).

## Sections

- Hero / introduction
- About me
- Skills
- Work experience
- Education
- Contact

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
npm run start
```

## Content

All profile content (summary, skills, experience, education) lives in [`src/lib/data.ts`](src/lib/data.ts) — edit that file to update the site.
